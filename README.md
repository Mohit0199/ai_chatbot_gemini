# 🤖 Google Gemini AI Chatbot with Streamlit

A simple AI chatbot built using Google Gemini-Pro and Streamlit, featuring a conversational UI and session-based chat history.

---

## 📌 Features
- **Conversational AI** powered by Google Gemini-Pro
- **Streamlit UI** for an interactive chat experience
- **Session-based memory** to retain chat history
- **Environment variable support** for secure API key handling

---

## 🛠️ Installation & Setup

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/your-username/google-gemini-chatbot.git
```

### 2️⃣ Create a Virtual Environment
```bash
python -m venv venv
source venv/bin/activate  # macOS/Linux
venv\Scripts\activate    # Windows
```

### 3️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```

### 4️⃣ Set Up Environment Variables
Create a `.env` file in the project root and add your Google Gemini API key:
```
API_KEY=your-google-gemini-api-key
```

### 5️⃣ Run the Chatbot
```bash
streamlit run app.py
```

---

## 📜 Usage
- Enter a message in the input box.
- AI will respond based on the conversation history.
- Type naturally, and enjoy chatting with the AI!
